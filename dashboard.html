Methodology and limitations: Metrics are descriptive aggregates from a synthetic retail pickup dataset. Pickup status comes from the supplied data; it is not independently recalculated using an SLA. Differences between shifts do not establish causality. No staffing intervention, customer wait reduction, or cost saving has been implemented or measured. This dashboard is an HTML portfolio artifact, not a Power BI report.
